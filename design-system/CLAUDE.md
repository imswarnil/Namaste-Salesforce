# CLAUDE.md — design-system/

The NS Design System: a plain-CSS SCSS system compiled to one stylesheet, plus
the styleguide site published to https://salesforce.imswarnil.com/. It lives
inside the Namaste Salesforce Ghost theme repo but is NOT part of the theme
zip (gulp `zipper` and `action-deploy-theme` both exclude it). The theme's own
CSS in `../assets/css/` is a sibling, not a consumer — keep the two in step by
hand when a token changes.

## Layout

```
src/scss/screen.scss   the manifest — @use order IS the cascade; never reorder casually
src/scss/0-abstracts/  _tokens.scss (every custom property) + _fonts.scss
src/scss/1-base/       reset, element typography, .gh-content article styles
src/scss/2-layout/     containers, header (CSS drawer + dropdowns), footer
src/scss/3-components/ 27 partials: buttons … quiz, progress, pager, media, code, pricing
src/scss/4-templates/  page templates + _sections.scss (bands) + _trail.scss
src/scss/5-utilities/  patterns + helpers, allowed to win
src/js/nsds.js         optional runtime; copied to dist/js by the build
src/fonts/             Figtree woff2 — copied to dist/fonts by the build
dist/                  GENERATED by `npm run build`, committed on purpose
*.html, templates/     the styleguide site (static, links ./dist/css/screen.css)
DESIGN.md, design-guidelines.md, design-components.md, llms.txt  the AI-readable spec
```

## Commands

```bash
npm ci
npm run build    # sass → dist/css/screen.css + .min.css, copy fonts + js
npm run watch
npm run serve    # :4322
npm run stage    # _site/ exactly as Pages publishes it (adds CNAME + .nojekyll)
```

Run `npm run build` after ANY scss/js edit — `dist/` is committed and CI
fails on drift (`git diff --exit-code` after building).

## Rules

- **All values route through the custom properties in `_tokens.scss`.**
  Components consume `var(--token)`; raw hex only in `0-abstracts`. Dark
  overrides live in BOTH `html[data-theme=dark]` and the
  `prefers-color-scheme: dark` block for `html:not([data-theme])` — keep the
  two blocks identical.
- **No `color-mod()`.** dart-sass passes it through and browsers drop the
  declaration (this silently killed `--border-soft` for a month). Use
  `rgba()`.
- The rem scale assumes `html { font-size: 62.5% }` (1rem = 10px).
- Partials are plain CSS in .scss files on purpose — no nesting, mixins or
  functions. The API is class names and custom properties.
- Fonts are `url(../fonts/…)` relative to the compiled CSS — `dist/css/` and
  `dist/fonts/` must stay siblings.
- Every HTML page inlines the same header/footer chrome; gallery pages use
  the `.docs-shell` layout, template pages carry a `.template-bar` and the
  publication's own header. A new component gets: a partial, an `@use`
  line, a `.specimen` in components.html, a row in design-components.md.
- Verify a page with `python3 …/checkclasses.py page.html` (unknown class
  names = 0, tag balance ok) and at 360px width.

## Deploy

`main` → `.github/workflows/design-system.yml` (path-filtered to this
folder) → GitHub Pages at https://salesforce.imswarnil.com/. The workflow
runs `npm run stage`, which writes `_site/CNAME` — a deploy that ships no
CNAME drops the custom domain on the next publish. DNS: Cloudflare CNAME
`salesforce` → `imswarnil.github.io` (proxied).
