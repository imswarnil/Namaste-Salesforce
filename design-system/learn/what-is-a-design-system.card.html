A design system is the shared source of truth — the smallest set of decisions and building blocks — that keeps a product consistent as many people design and build it together, faster than redesigning each screen from scratch.

01
Tokens
The atomic values: color, type, spacing, radius, shadow, motion — each named once, referenced everywhere.
02
Components
Reusable UI built only from tokens — Button, Card, Input — so a token change updates every instance at once.
03
Patterns
Components composed into real flows — a course catalog, a checkout, a settings page.
04
Guidelines
The written rules — voice, principles, dos/don'ts — that keep new work on-brand without a review for every pixel.
05
Governance
Who owns it, how it changes, and how adoption is tracked — without this, a system decays into another abandoned folder.
