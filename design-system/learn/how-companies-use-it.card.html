SALESFORCE / SLDS
Internal consistency at enterprise scale. The Lightning Design System is the actual inspiration for this project's blue — hundreds of internal teams building Sales/Service/Marketing Cloud share one token set so the platform feels like one product.
SHOPIFY / POLARIS
Ecosystem enforcement. Powers Shopify's own admin AND every third-party app in the App Store — merchants get a consistent experience even though thousands of outside developers wrote the apps.
GOOGLE / MATERIAL
Public product in its own right. Ships as open specs + code that any Android/web team can adopt — the system itself became a distributable brand asset, not just an internal tool.
ATLASSIAN / ADS
Cross-product cohesion. Keeps Jira, Confluence and Trello — separate codebases, separate teams — visually and behaviorally aligned as one company.
IBM / CARBON
Open-sourced governance. Built for IBM's enterprise software, then open-sourced with public contribution rules — a model for a system that outlives any one team.
