01
Link the tokens
<link rel="stylesheet" href="styles.css"> — every color, font, radius and shadow becomes a CSS variable immediately.
02
Load the bundle, mount components
Script-tag _ds_bundle.js, then const { Button, CourseCard } = window.NamasteUIDesignSystem_e97b71.
03
Read the 5 Design Principles
In readme.md — hairline-as-structure, mono-as-data, one signal color, sharp geometry, instant motion. Check new work against them before shipping.
04
Start from the UI kit, not a blank page
ui_kits/lms/ is a full reference build (home, catalog, course, training, docs) — copy the closest screen and edit content.
05
Extend, don't override
New components should be built from the same tokens and read the Principles list — never a one-off color or shadow bolted onto an existing component.
