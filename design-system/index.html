Why NS Design System

Small surface, serious system

The whole API is class names and custom properties. No build step to adopt it — one link tag and a learning site is styled, rails and quizzes included.

Token-first colour

The Salesforce Lightning blue ramp and the navy grays live on :root; every component paints with semantic tokens, never raw hex.

Two real themes

Dark mode is a full custom-property flip that honours the OS preference by default — not an inversion filter bolted on later.

Learning-native components

Quiz, progress bars and rings, the lesson rail, prev/next lesson navigation, the training trail — the pieces a course site needs, not just buttons.

Sections, not just components

Heroes, value props, split rows, stats bands, pricing, testimonials, FAQ and CTA bands — a page is a stack of bands you already have.

Five templates

A full single-page site, the course catalogue, a course landing, the lesson player and the training trail — responsive, with the mobile drawer and lesson bar wired in.

Zero runtime

Tabs, accordions, the quiz and the mobile drawer are CSS. The optional nsds.js adds the theme toggle, scroll-spy contents and copy buttons in five kilobytes.

Quick start

Ship it with one link tag

Grab the compiled stylesheet, add the optional runtime, and start pasting markup from the gallery.

Full install guide
index.html 
<!-- the whole system, both themes -->
<link rel="stylesheet" href="https://salesforce.imswarnil.com/dist/css/screen.min.css" />

<!-- optional: theme toggle, scroll-spy contents, copy buttons -->
<script src="https://salesforce.imswarnil.com/dist/js/nsds.js" defer></script>
  1. Link the CSS
  2. Copy markup from the gallery
  3. Retheme by overriding tokens

Architecture

Six layers, one cascade

The @use order in screen.scss is the specificity strategy. Later layers may win; earlier ones never fight back.

How it works
  1. 0 — AbstractsDesign tokens and font faces. No selectors that paint.2 partials
  2. 1 — BaseReset, element typography, article content styles.3 partials
  3. 2 — LayoutThe frame: containers, header with the mobile drawer, footer.3 partials
  4. 3 — ComponentsButtons to quizzes — every reusable piece, documented live.27 partials
  5. 4 — TemplatesThe section grammar plus one file per page template's own layout.16 partials
  6. 5 — UtilitiesPatterns and helpers — the only layer allowed to win.2 partials
