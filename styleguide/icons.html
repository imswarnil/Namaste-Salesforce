Icons

One partial, one <svg>, no third party. Every icon on the site is inline SVG drawn from partials/icons.hbs — there is no icon font, no CDN and no request before an icon paints. Rendered here straight from that file, so this page cannot go stale.

How to use one

default — 1em, inherits colour
sized with utilities
coloured by its container

{{> icons name="arrow-right"}} is the whole API. The class parameter adds utilities; title swaps aria-hidden for a label when the icon carries meaning the text does not. Every svg also carries .ns-icon, the design system’s icon primitive: 1em square, baseline-aligned, flex: none, currentColor — the same contract the app’s sprite icons use.

Adding one is adding a {{#match name=…}} line to partials/icons.hbs: 24×24 viewBox, stroke-width 1.7, round caps and joins, artwork inside a ~3px margin, currentColor. The brand marks at the foot of that file are the one exception — they are drawn solid, because that is how those marks are specified.
