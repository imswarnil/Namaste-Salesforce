Syntax highlighter

A code block that looks like the tool the reader is learning: a title bar carrying the filename and language, a copy button that confirms itself, and optional line numbers. code.js tokenises and injects the .ns-tok-* spans — there is no highlighting library.

Default

.ns-code

Ghost's editor emits a bare <pre><code class="language-x">. assets/js/code.js upgrades that into this structure and tokenises it; the copy button is wired by the system's own assets/js/nsds/code.js through [data-code="copy"]. The theme's old .ns-syntax is gone.

Terminal

zsh
sf org create scratch --alias devsf project deploy start

Plain

  // bulk-safe: one query, one update
  public static void setRating(List<Account> accs) {
      for (Account a : accs) {
          a.Rating = a.AnnualRevenue > 1000000 ? Hot : Warm;
      }
      update accs;
  }
--plain

--full breaks the block out to the full content width inside an article; --wrap soft-wraps instead of scrolling; --dark forces the navy editor surface. The token palette lifts automatically on dark grounds.
